# HomeoVault Developer Core Engine Integration Guide

This guide explains how future modules (such as Medicine Cataloging, Inventory Management, and Reports) must consume the reusable utilities and frontend components introduced in Phase 4.

---

## 1. Backend Core Utilities

### A. Dynamic Database Queries (`queryBuilder.js`)
Use `buildSelectQuery` in repositories to automatically handle filtering, pagination, sorting, and search matching without writing raw strings for each query:

```javascript
import { buildSelectQuery } from '../utils/core/queryBuilder.js';
import BaseRepository from '../repositories/base.repository.js';

class InventoryRepository extends BaseRepository {
  constructor() {
    super('inventory', 'id');
  }

  async getFilteredInventory(queryOptions) {
    // queryOptions is generated by the queryParser middleware!
    const { queryText, countText, queryParams, countParams } = buildSelectQuery({
      tableName: this.tableName,
      fields: ['id', 'remedy_id', 'quantity', 'created_at'],
      filters: queryOptions.filters,
      search: queryOptions.search,
      sort: queryOptions.sort,
      pagination: queryOptions.pagination,
      defaultSort: 'created_at DESC'
    });

    const dataResult = await this.executeQuery(queryText, queryParams);
    const countResult = await this.executeQuery(countText, countParams);

    return {
      records: dataResult.rows,
      totalRecords: parseInt(countResult.rows[0].count, 10)
    };
  }
}
```

### B. In-Memory Caching (`cache.js`)
Use the cache to speed up read-heavy data (e.g. settings or remedy catalogs) and flush it on updates:

```javascript
import cache from './utils/core/cache.js';

// Retrieve or Set
async function getCachedRemediesList() {
  const cacheKey = 'remedies:all';
  let list = cache.get(cacheKey);
  
  if (!list) {
    list = await db.query('SELECT * FROM remedies');
    cache.set(cacheKey, list, 600); // Cache for 10 minutes (600s)
  }
  return list;
}

// Invalidate on mutations
async function createRemedy(data) {
  await db.query('INSERT INTO remedies...', [data]);
  cache.del('remedies:all'); // Invalidate key
}
```

### C. Decoupled Communication (`events.js`)
Emit and listen to events to keep services isolated:

```javascript
import appEvents from '../utils/core/events.js';

// Inside Auth Service
appEvents.emit('auth:login', { userId, email, ipAddress });

// Inside System Logger / Notification Service (Decoupled Listener)
appEvents.on('auth:login', ({ userId, email, ipAddress }) => {
  auditLogger.log(userId, 'LOGIN', `Logged in from IP: ${ipAddress}`);
});
```

### D. Audit Trails (`auditLogger.js`)
Log security and inventory changes:

```javascript
import auditLogger from '../utils/core/auditLogger.js';
import { AUDIT_ACTIONS } from '../utils/core/constants.js';

// Record change asynchronously
auditLogger.log(
  remedyId, 
  AUDIT_ACTIONS.USER_UPDATE, 
  { field: 'potency', from: '30C', to: '200C' }, 
  operatorUserId
);
```

### E. RBAC Controls (`permissionManager.js`)
Use the manager to verify actions or control sidebar UI lists:

```javascript
import permissionManager from '../utils/core/permissionManager.js';

if (!permissionManager.hasPermission(userRole, 'users:status')) {
  throw new AppError('Unauthorized operation.', 403);
}
```

## 2. Frontend Core Framework (`window.core`)

### A. HTTP Requests Wrapper (`window.core.api`)
All AJAX requests should use the unified API Client. It automatically manages content headers, displays the loading spinner, and displays error toast notifications if responses return failures:

```javascript
// GET request with query params
window.core.api.get('/api/users', { page: 1, limit: 10 })
  .then(res => {
    console.log('User list:', res.data);
  })
  .catch(err => {
    // Toast error notifications are handled automatically by core.js!
  });

// POST request with JSON body
window.core.api.post('/api/users/profile', { first_name: 'John' })
  .then(res => {
    window.core.toast.success('Saved', 'Profile updated successfully.');
  });
```

### B. Input Validation (`window.core.validate`)
Run checks on user entries prior to dispatching network requests:

```javascript
const emailValue = document.getElementById('email-field').value;

if (!window.core.validate.required(emailValue)) {
  alert('Email is required!');
} else if (!window.core.validate.email(emailValue)) {
  alert('Please enter a valid email address!');
}
```

### C. Confirmation Modals (`window.core.dialog`)
Prompt actions (such as deletions) using the Material Confirm Dialog:

```javascript
window.core.dialog.confirm({
  title: 'Delete Remedy',
  message: 'Are you sure you want to delete Arnica Montana? This action is permanent.',
  confirmText: 'Delete Record',
  onConfirm: () => {
    window.core.api.delete(`/api/remedies/${remedyId}`)
      .then(() => window.core.toast.success('Deleted', 'Remedy removed.'));
  }
});
```

### D. Dynamic Pagination Footer (`window.core.ui`)
Render pagination controls automatically inside any table container:

```javascript
function loadPage(pageNumber) {
  window.core.api.get('/api/remedies', { page: pageNumber })
    .then(res => {
      // 1. Render Table Rows...
      
      // 2. Render Pagination Controls
      window.core.ui.renderPagination('pagination-container-id', {
        page: res.data.pagination.page,
        totalPages: res.data.pagination.totalPages,
        totalRecords: res.data.pagination.totalRecords,
        onPageChange: (newPage) => loadPage(newPage) // Callback load
      });
    });
}
```
